# 💌 Secret Valentine

<div align="center">
  <h3>A modern, digital love letter delivery system for Valentine's Day.</h3>

## 📖 About

**Secret Valentine** is an application designed to allow people to express their love and appreciation anonymously to their crush, friends, and loved ones. Think of it as a modern-day pigeon delivering your secret love letters, dressed up in a beautiful rosé, pink, and purple color palette representing the code of love.

## 🎯 Goal & Purpose

Our purpose is to deliver a fun, safe, and engaging way to reveal your secret love. 
In a world that is overly connected, taking a moment to send an anonymous, thoughtful message brings back the charm of traditional love letters, modernized for today.

## 🚀 Background & Story

We launched the first version of this app last year, and it was a massive success at our school! However, we became victims of our own success: our free-plan database quickly reached its maximum capacity, forcing us to constantly migrate between different email addresses to keep the service running. 

This new and improved version is built to be more robust, scalable, and beautifully designed using modern web technologies to handle all the love letters you can send!

## 🎨 Artistic Direction (DA)

- **Theme:** Saint Valentine's Day 💝
- **Color Palette:** Rosé, shades of pink, and deep purples.
- **Vibe:** Romantic, mysterious, modern, and engaging.

## 🛠️ Tech Stack & Architecture

Inside the `app_design_2` folder, this project has been reimagined with a modern stack to avoid the database issues from the past:

- **Frontend:** React + TypeScript, Vite
- **Styling:** Tailwind CSS + Radix UI components (for accessible, elegant UI)
- **Animations:** Framer Motion (for smooth, lovely transitions)
- **Backend & Database:** Firebase (to support an active user base, ensuring reliable and scalable delivery of anonymous messages)

## 📦 Getting Started

To run the application locally:

1. **Navigate to the core application folder:**
   ```bash
   cd app_design_2
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```
   *(Note: The project uses React 18 and Vite.)*

3. **Start the development server:**
   ```bash
   npm run dev
   ```
